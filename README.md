# Antibiotic Lab: Outsmarting Resistance

항생제 내성을 극복하기 위해 항생제에 보조제를 함께 쓰는 방식이 연구되고 있다는 것을 알리고, 약물 개발 과정을 직접 체험해 볼 수 있도록 만든 교육용 게임입니다.

플레이어는 연구원이 되어 한정된 예산 안에서 균의 방어 수단을 분석하고, 약을 조합하고, 배양 시험으로 결과를 확인합니다. 정해진 조건(사멸률, 독성, 비용)을 모두 만족해야 약을 제출할 수 있습니다. 약을 함부로 많이 쓰면 균이 내성을 얻는다는 점도 게임 규칙 속에 담았습니다.

## 플레이 방법

### 웹 (권장)
1. (https://johyeongi980-tech.github.io/antibiotic-lab/ )에 접속합니다.
2. PC 브라우저(크롬, 엣지, 파이어폭스 최신 버전)를 권장합니다. 모바일과 터치 화면에서는 일부 설명이 보이지 않을 수 있습니다.
3. 처음 열 때 로딩에 몇 초가 걸릴 수 있습니다.
4. 진행 상황은 **사용 중인 브라우저에만** 저장됩니다. 다른 기기, 다른 브라우저, 시크릿 모드에서는 이어하기가 보이지 않습니다.

### 데스크톱 (Windows)
1. GitHub에서 파일을 내려받아 압축을 풉니다.
2. `AntibioticLab.exe`를 실행합니다.
3. 서명하지 않은 프로그램이라 Windows 보안 경고가 나올 수 있습니다. 직접 만든 게임이므로 추가 정보 → 실행을 누르면 됩니다.
4. 진행 상황은 컴퓨터의 사용자 데이터 폴더에 저장됩니다.

### 조작
- 마우스로 모든 조작을 합니다.
- 약 한 번 만들기: 병원체 분석 → 약물 조합 → 배양 실험 → 제출

## 주의 사항
- 게임 속 수치, 약물, 균은 이해를 돕기 위해 단순화한 가상의 것이며 실제와 일치하지 않습니다. 실제 약물은 오랜 연구와 임상시험을 거쳐 개발됩니다.
- 항생제는 반드시 의사의 처방에 따라 복용하고, 증상이 나아져도 처방받은 기간을 끝까지 복용하세요. 남은 항생제를 다른 사람에게 주지 마세요. 감기와 독감 같은 바이러스 질환에는 항생제가 듣지 않습니다.
